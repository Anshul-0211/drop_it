# Glossary: drop_it

This glossary defines the domain concepts, technical terms, acronyms, and project-specific terminology used in the `drop_it` codebase.

---

## 1. Domain Terminology

*   **Capture**: The process of saving links, notes, images, or documents to the database, either via the Telegram bot or the web dashboard.
*   **Inbox**: The default view on the dashboard showing active, unread, and untrashed items.
*   **Saved**: Starred or bookmarked items.
*   **Trash**: The folder containing soft-deleted items. Trashed items are automatically purged after 7 days.
*   **Read State**: The status of an item, either `read` or `unread`.
*   **Folder**: A custom folder created by a user to organize their captured items.
*   **Linking Token**: A temporary 24-character token used to link a Telegram account to a user account.
*   **Link Code**: A 6-character, 10-minute code used for manual account linking (not fully implemented).

---

## 2. Technical Terminology

*   **Webhook Mode**: A method where the Telegram API sends update payloads to the application's webhook endpoint (`/api/telegram/webhook`) in real-time.
*   **Polling Mode**: A local development fallback where the application periodically requests updates from the Telegram API using the `getUpdates` endpoint.
*   **Signed URL**: A temporary, secure URL generated by Supabase Storage to allow authenticated users to view private documents.
*   **Soft Delete**: Marking an item as deleted by setting its `deleted_at` timestamp instead of deleting the row from the database.
*   **Timing-Safe Comparison**: Using constant-time algorithms (`crypto.timingSafeEqual`) to prevent timing attacks when verifying secret tokens.
*   **Double-Tab Security**: Setting `popup.opener = null` when opening links in new tabs to prevent reverse-tabnabbing security issues.
*   **Scraper Fallback Chain**: The sequential process of fetching page previews (Microlink API -> Meta tags -> HTML title).

---

## 3. Acronyms

*   **RLS**: Row Level Security (PostgreSQL security mechanism).
*   **JWT**: JSON Web Token (used for NextAuth sessions).
*   **OAuth**: Open Authorization (used for GitHub sign-in).
*   **CDN**: Content Delivery Network (Cloudinary).
*   **RPC**: Remote Procedure Call (database functions invoked via API).
*   **HMAC**: Hash-based Message Authentication Code.
*   **CSR**: Client-Side Rendering.
*   **MIME**: Multipurpose Internet Mail Extensions (file formats).
